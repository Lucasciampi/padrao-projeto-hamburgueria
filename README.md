# Projeto Hamburgueria

Projeto destinado a estudo acadêmico de Arquitetura e Projeto de Software.

Aplicação dos padrões Singleton, AbstractFactory, FectoryMethod, Bridge, Decorator, State, Observer, Strategy, ChainOfResponsability, Builder, Composite, Template Method, Mediator, Facade, Memento, Prototype, Flyweight, Iterator, Visitor, Adapter, Command, Proxy e Interpreter em um contexto de uma Hamburgueria.
